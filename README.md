# Power BI – Retail & Sales Data Analysis

## 📊 Project Overview

This project was completed as part of a **Data Technician Bootcamp with Leep Talent**, focusing on using Microsoft Power BI to clean, transform, analyse, and visualise data.

The project involved developing interactive reports, applying DAX calculations, and exploring retail and sales data to identify trends, monitor performance, and communicate insights through effective data storytelling.

## 🛠️ Skills & Tools Used

**Tools:** Microsoft Power BI, Power Query, DAX (Data Analysis Expressions)

- **Data Cleaning & Transformation:** Used Power Query to clean, transform, and prepare datasets for analysis, including managing data types, removing unnecessary information, and structuring data.
- **Data Modelling:** Worked with Power BI semantic models to organise data and support accurate reporting.
- **DAX Calculations:** Created calculated columns and measures using DAX to perform calculations and analyse key business metrics.
- **Interactive Reports:** Designed Power BI reports using slicers and filters to allow users to explore data dynamically.
- **Data Visualisation:** Developed bar charts, line charts, pie charts, and maps to visualise sales performance, trends over time, category comparisons, and geographical distributions.
- **Data Storytelling:** Presented complex datasets through clear and meaningful visualisations to highlight trends and support data-driven decision-making.

## 📈 Project Highlights

- Imported, cleaned, and transformed datasets using Power Query.
- Explored data modelling and semantic models within Power BI.
- Applied DAX calculated columns and measures to support analysis.
- Created interactive reports with slicers and filters.
- Used various visualisations to explore retail and sales performance.
- Developed skills in presenting analytical findings through accessible dashboards.

## 🎯 Key Learning Outcomes

This project strengthened my practical understanding of **data transformation, data modelling, DAX, interactive reporting, and business intelligence**.

It also developed my ability to turn raw data into meaningful visual insights, communicate trends effectively, and support informed business decisions through data storytelling.
